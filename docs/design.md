# Flow 참고 조사 → Still 설계

조사일: 2026-09-30. 후기의 과거 버전 동작을 현재 Flow 동작으로 단정하지 않습니다.

## 참고 자료

1. [Flow 공식 홈](https://www.flow.app/): 미니멀 디자인, 네이티브 앱, 가입 없이 기본 타이머를 쓰는 방향.
2. [공식 기능](https://www.flow.app/features): 집중과 반복 휴식, 종료 알림, 세션 이름,
   일/주/월/년 통계, 잠금화면의 타이머 접근. 앱 차단과 캘린더 연동은 범위 밖.
3. [공식 Help](https://www.flow.app/help): Controls and Elements 및 알림·동기화 관련 도움말 구조.
   페이지의 문서 항목은 동적 UI여서 개별 답변 본문을 확보하지 못했음.
4. [App Store 상세 후기](https://apps.apple.com/us/app/flow-focus-pomodoro-timer/id1423210932?platform=iphone&see-all=reviews):
   2022년 디자인 후기, 2021년 위젯 후기, 2024–2025년 워치 알림과 시간 가시성 후기 등을 검토.
5. [국내 사용 후기](https://www.korea-iphone.com/blog/rfDoywTiHgrp.html):
   큰 남은 시간, 회차 표시, 최소 조작, 통계, 작업 중 시간을 볼 수 있는 점에 대한 평가.
   오래된 후기의 무료 범위와 동기화 설명은 현재 기능 판단에 사용하지 않음.
6. [공식 사이트의 Live Activity 이미지](https://framerusercontent.com/images/G1Zr3zYJQx1LVs7hWNBxtX8Xoc.webp):
   화면 밖에서도 세션 상태를 보는 디자인 참고.

## 화면

- 타이머: 작은 상태 → 큰 고정폭 시간 → 회차 점 → 초기화 / 재생 / 건너뛰기.
- 폰 하단: 타이머 / 기록 / 설정. 오늘 기록은 메인 하단에 작게.
- 기록: 오늘 총 시간과 회차, 일주일 막대 그래프, 날짜별 내역.
- 설정: 시간 / 자동 시작 / 종료 알림 / 화면의 네 그룹.
- 워치: 작은 화면에 시간과 세 조작을 배치. 설정과 기록은 스크롤 화면.
- 위젯: 어두운 바탕, 작은 상태, 큰 시간, 점과 시작 버튼.

## 타이머 구현 원칙

시간을 초마다 저장·감산하지 않고 `SystemClock.elapsedRealtime()` 종료 시각에서 계산.
프로세스를 다시 열어도 동일한 남은 시간. 완료 시 상태를 먼저 다음 단계로 옮겨
같은 종료 이벤트가 다시 들어와도 현재 단계의 완료 기록이 중복되지 않게 함.
자동 시작은 종료 이벤트에만 적용. 지연된 알림으로 지나간 여러 회차를 임의 기록하지 않음.

정확한 알람 및 위젯 구현 참고:
- [Android 알람 가이드](https://developer.android.com/develop/background-work/services/alarms)
- [RemoteViews Chronometer](https://developer.android.com/reference/android/widget/RemoteViews)

UI는 Android 기본 View와 직접 그린 그래프를 사용. 폰과 워치가 공통 Android library를 공유하며,
외부 런타임 라이브러리 없이 작고 간단한 APK를 만듭니다.
